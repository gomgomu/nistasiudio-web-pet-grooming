# PetFlow Antigravity Starter Pack

Files in this package:

- `AGENTS.md` — coding and agent operating rules
- `docs/IMPLEMENTATION_PLAN.md` — architecture and delivery phases
- `docs/ERD.md` — Mermaid database ERD and modeling rules
- `docs/TASKS.md` — sequential Antigravity task list

Recommended first action:

2. Put `docs/*` in the repository.
3. Ask Antigravity to execute `PF-001` only.
4. After each task, require tests/typecheck/lint before proceeding.
